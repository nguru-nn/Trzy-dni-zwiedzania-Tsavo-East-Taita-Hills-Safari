# Trzy-dni-zwiedzania-Tsavo-East-Taita-Hills-Safari
Interactive 3D Mapbox map of a 3-day road safari from Diani Beach to Tsavo East and the Taita Hills Wildlife Sanctuary, Kenya, with nights at Voi Safari Lodge and Salt Lick Safari Lodge. It shows an in-park game drive, satellite terrain and a clickable itinerary.
